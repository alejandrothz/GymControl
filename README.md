# GymControl

Aplicación web para la administración de miembros y pagos de un gimnasio.

## Objetivo

GymControl permitirá al personal autorizado de un único gimnasio iniciar sesión y realizar operaciones de administración de miembros y registro de pagos, de acuerdo con los permisos asignados a cada rol.

## Tecnologías previstas

- AWS Amplify
- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
